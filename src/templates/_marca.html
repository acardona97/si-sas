{# ══════════════════════════════════════════════════════════════════ Sistema de marca SÍ S.A.S. Macros que inlinean el SVG de la marca (para heredar color por currentColor y permitir la micro-animación de asentado). No usar para la marca: siempre estos macros. si_logo(variant, tone, size, animate, cls) variant: 'full' -> "SÍ S.A.S." completo, una sola pieza tipográfica 'core' -> "SÍ" (núcleo, sin descriptor) 'mark' -> isotipo (tilde + cola de la Í), para espacios muy reducidos o como marca de agua 'app' -> isotipo sobre contenedor sólido (ícono de app/perfil) tone: 'currentColor' (por defecto, hereda del CSS) | 'light' (fuerza navy, para fondos claros) | 'dark' (fuerza blanco, para fondos oscuros/navy) size: alto en px (ancho se ajusta solo, según relación del viewBox) animate: si es true, agrega la clase que dispara el asentado de la tilde/cola en el primer render (respeta prefers-reduced-motion, ver style.css) ══════════════════════════════════════════════════════════════════ #} {% macro si_logo(variant='full', tone='currentColor', size=None, animate=False, cls='') %} {%- set color = '#004571' if tone == 'light' else ('#FFFFFF' if tone == 'dark' else 'currentColor') -%} {%- set wrapper_cls = 'si-logo si-logo--' ~ variant ~ (' si-logo--animate' if animate else '') ~ (' ' ~ cls if cls else '') -%} {%- set style = 'color:' ~ color ~ (';height:' ~ size ~ 'px' if size else '') -%} {% if variant == 'core' %} {% elif variant == 'mark' %} {% elif variant == 'app' %} {% else %} {% endif %} {% endmacro %}
